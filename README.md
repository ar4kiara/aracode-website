# Ara Code Studio — official project website

Website: https://aracode.e-link.web.id  
Cloudflare Pages: `aracode-website` (production branch `main`)  
Contact: founder@e-link.web.id

This is the public informational website for **Ara Code Studio**, an independently developed Android-first coding environment.

## Deploy
Static HTML/CSS/JS in repository root. Cloudflare Pages settings:
- Framework preset: None
- Build command: empty
- Build output directory: `/`
- Production branch: `main`

Changes to `main` deploy automatically through GitHub-connected Cloudflare Pages.
