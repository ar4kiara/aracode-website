Monaco editor, local workspace management, project preview, terminal, Git workflows, SSH/SFTP, and AI Ask/Edit/Agent. Availability depends on build, platform and gateway. The README documents React/Vite/Capacitor, optional Node gateway, Cloudflare Worker/D1 licensing and Android build pipeline.
